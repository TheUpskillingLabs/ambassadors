# Ambassador button

`ambassador-button-1.25in.png` is print-ready art for Sticker Mule's 1.25" round button: 1.75" square at 600 dpi, RGB.

- The orb mark (`brandkit/assets/orb-mark.png`) sits on ink, ringed by THE UPSKILLING LABS on top and AMBASSADOR below. The type is Geologica, set in capitals with wide letter-spacing.
- Geometry comes from Sticker Mule's 1.25" template. The button edge is 1.25" across and the cut line is 1.623". Art between the two wraps around the rolled edge. The text stays on the flat of the face, from 12.25 to 14.05 mm off centre.
- Sticker Mule recommends CMYK, so check the teal on the proof.
